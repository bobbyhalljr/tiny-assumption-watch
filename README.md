# tiny-assumption-watch

Tiny TypeScript assumption watcher. A report records what it assumed and rebuilds only when an assumption moves past its tolerance. No API key. No network.

```bash
npm install
npx tsx watch.ts
```

Example output is in `output.txt`. All inputs are made up. This is a small teaching model, not any vendor's implementation.
